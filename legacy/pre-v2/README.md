# Pre-v2 Archive

This folder contains legacy implementation artifacts that predate the current v2 rebuild direction for Ecom Learning.

## Why these files were archived
They were moved out of the active app path to reduce confusion and avoid accidentally building new work on top of older assumptions.

Typical reasons for archival:
- older content/data model that does not match the current v2 Chapter 3 contract
- older slide-based content structures
- older project-based route assumptions
- older in-app kanban or sample/demo scaffolding not intended as the active v2 path

## Important note
These files are retained for reference and recovery only.
They are **not** the active source of truth for the current v2 implementation.

- product/project docs: `projects/ecom-learning/`
- planning docs: `knowledge/projects/ecom-learning/`
